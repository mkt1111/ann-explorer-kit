# ANN Explorer Kit

An educational site introducing artificial neural networks, with small in-browser simulations.

## Features

- Sections on neuron basics, layers, activation functions, training and backpropagation
- Single-neuron playground with selectable activation functions (sigmoid, ReLU, tanh)
- Network training visualizer for simple logic problems (AND, OR, XOR)
- Cart-pole balancing simulation
- Background section on the history and real-world applications of neural networks

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```
